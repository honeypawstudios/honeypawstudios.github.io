# Honeypaw Studios

Welcome to Honeypaw Studios' official website repository! 🐾

## About

Honeypaw Studios is a game development studio crafting extraordinary gaming experiences with passion and creativity.

## Tech Stack

This website is built with:
- **React** - UI framework
- **Vite** - Build tool and dev server
- **TailwindCSS** - Utility-first CSS framework

## Development

To run the development server:

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```
